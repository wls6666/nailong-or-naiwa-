它是如何判断的？

这是一个从零训练的小型 CNN。图片在浏览器中转换为 128 × 128 的 RGB tensor，再由 ONNX Runtime Web 执行真实模型推理，再应用验证集校准的拒识阈值。页面没有服务器端预测接口。

模型可以识别奶龙、奶蛙，并尝试拒绝其他图片。“都不是”能力基于有限负样本训练，无法覆盖现实世界中的所有图片。低置信度拒识时显示最高目标类概率，不会将其伪装成“都不是”的置信度。softmax 概率不代表经过校准的正确率。
